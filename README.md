# AI Delivery

面向外部 AI 的产品交付资产发布仓。

这里存放能让**你自己的 AI**（Claude Code、Codex 或其他 agent）直接使用我们产品的材料：技能（Skill）、MCP 工具合同、提示词与插件清单。

- 装上之后，你的 AI 就了解产品的对象、接口与边界，可以帮你查问题、做诊断、给建议。
- 每个产品按**产品版本**分目录。你装的是哪个版本的产品，就拉哪个版本的材料。
- 只读使用，不影响你在产品界面里的操作。

## 怎么开始

一句话告诉你的 AI：

```
拉取 https://github.com/Yozily/ai-delivery 的目录索引，
告诉我里面有哪些产品、各自支持哪些 AI 宿主。
```

然后按它的指引，或直接看 [INSTALL.md](INSTALL.md) 完成单个产品的安装。

## 目录

| 路径 | 内容 |
| --- | --- |
| [INDEX.md](INDEX.md) | 产品线、版本与状态的总索引——**从这里找你要的那一版** |
| [INSTALL.md](INSTALL.md) | 安装步骤与宿主差异 |
| `_shared/` | 通用说明、模板与发布工具（不是某个产品的资产） |
| `<产品线>/<版本>/` | 单个产品的某一版交付资产 |

## 约定

- 版本目录里的内容由产品仓生成，**不在此仓手工维护**。
- 旧版本保留，便于已安装的用户回查；版本若被撤回会在 [INDEX.md](INDEX.md) 标注。
- 本仓内容公开，不含任何凭据、内部地址或内部资料。如发现敏感信息，请通过 Issue 告知。
