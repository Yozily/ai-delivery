# 一句话安装提示词

## 标准句式

```
拉取 https://github.com/Yozily/ai-delivery 的 <产品线>/<版本> 目录，
安装其中的 skills/<技能名>，
然后阅读该目录下的 README 与 references，告诉我你能用它做什么、有哪些操作是不允许的。
```

三处必须填实际值，**不能只给产品名**——只给产品名时客户 AI 会拉到最新版，与客户实际安装的产品版本错配；错配时它按旧工具名调用，看起来成功、结果却是错的。

## 变体

**只要清单、先别装**：

```
拉取 https://github.com/Yozily/ai-delivery 的 INDEX.md，
列出我关心的产品有哪些版本、各自支持哪些宿主、当前状态是不是 released。
```

**只装 MCP、不装技能**：

```
拉取 https://github.com/Yozily/ai-delivery 的 <产品线>/<版本>/mcp/<合同名>/contract.md，
按里面的传输方式和工具定义给我配置 MCP server，配置前先把工具清单和只读标记列给我确认。
```

**不用技能机制、只要提示词**：

```
拉取 https://github.com/Yozily/ai-delivery 的 <产品线>/<版本>/prompts/<提示词名>.md，
把内容展示给我，之后按它工作。
```

## 写提示词时的硬规矩

1. 给**仓库地址 ＋ 版本号**，两样都要。
2. 说清**这个版本的边界**（如"只读"），或紧邻位置说明。
3. 不承诺能力之外的事。没有真实验证过的能力不写进提示词。
4. 提示词不要求客户 AI 做它做不到的事（如"自动安装到某个固定目录"——宿主目录各不相同）。
