# PgTool

PgTool 产品测试工具链的 AI 技能。本目录是**当前版本，滚动更新**；更新后重新安装技能即可。当前内容对应的产品版本与来源提交见 [MANIFEST.json](MANIFEST.json)。

> 当前状态：**预览**。适用于 PgTool v3.0.1 之后的开发构建，未经完整黑盒验收；不适用于 v3.0.1 正式版（缺少技能用到的接口）。

## 一句话安装

把下面这段发给你的 AI：

```
拉取 https://github.com/Yozily/ai-delivery 的 pgtool 目录，
安装其中的 skills/pgtool，
然后阅读该目录下的 README、docs 与 references，告诉我你能用它做什么、有哪些操作是不允许的。
```

## 这套材料能做什么

| 能 | 不能 |
| --- | --- |
| 说明当前工单、产品型号、产线身份与环境 | 修改测试流程 |
| 概括测试流程的主要步骤 | 启动、停止、终止或重试测试 |
| 从最近运行反推本机在用的部署，判断是否晚于流程最后修改 | 重试记录同步 |
| 定位最近一次失败的运行与失败组，区分取消与测量超差 | 读取设备在线状态 |
| 归纳记录同步失败的原因与处理方 | 计算合格率（本机只有记录条数） |
| 按清单检查能否开始测试 | 回答云后台的问题（云端记录、全线统计、产品定义），会说明需在云后台查看 |

**只读。** 所有操作只读取信息，不会改变你的产品配置。

## 内容

| 形态 | 名称 | 用途 |
| --- | --- | --- |
| Skill | `pgtool` | 查询与诊断：工单与产线身份、流程与部署、开测前检查、失败诊断、测试记录与统计、同步失败原因 |
| 文档 | `docs/connect.md` | 安装方式、连接前提、服务地址与只读 HTTP 工具配置 |

`SKILL.md` 是入口，业务域内容在 `references/` 下按需读取。技能内说明各业务在客户端与云后台各能做什么；云后台暂无接口，验证后补进同一技能。

## 前提

- PgTool 桌面端已在这台电脑上启动。
- 你的 AI 运行在同一台电脑上，并能发 HTTP GET 请求（内置网页抓取、通用抓取类 MCP，或命令行工具）。不需要你提供地址或端口，详见 [docs/connect.md](docs/connect.md)。
- PgTool 接口当前没有访问认证，不要把它的端口转发或暴露到其他网络。

## 历史版本

PgTool 正式发版时，当时的内容会按版本号存一份快照到 `releases/` 下，供使用旧版本产品的用户安装。目前还没有快照。
