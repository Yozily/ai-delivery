# 能力现状

「可用」指接口存在且实测能读到；「受限」指能读但有明确限制；「不可用」指当前没有办法。

| 能力 | 状态 | 说明 |
|---|---|---|
| 环境、产线身份、工单 | 可用 | |
| 产品定义与生产配置是否绑定 | 受限 | 只能从生产上下文中字段是否为空判断 |
| 产品型号目录 | 不可用 | 当前返回空 |
| 型号与项目的对应 | 不可用 | 只能按名称推断 |
| 项目列表 | 受限 | 每项 200–400KB，常常读不全 |
| 流程大纲与节点 | 可用 | |
| 部署列表 | 受限 | 不分页、按 ID 排序、过滤参数不生效 |
| 本机当前部署 | 不可用 | 可从活跃执行或最近测试记录推断 |
| 执行列表 | 不可用 | |
| 活跃执行、工作台、调试快照 | 受限 | 依赖部署 ID 与哈希；可能返回会话绑定不存在 |
| 测试记录 | 受限 | 单条很大，结论字段在末尾常被截断；仍是诊断与定位部署的主要入口 |
| 死信事件 | 受限 | 服务重启后可能为空 |
| 同步状态与失败原因 | 可用 | 汇总不含错误码分组，需翻页归纳 |
| 设备在线状态 | 不可用 | |
| 流程修改、同步重试 | 不可用 | 只给建议，由用户在界面操作 |
| 启动、停止、终止、重试测试 | 不可用 | 本版本不开放，一律请用户在界面操作 |
