## 一句话安装

把下面这段发给你的 AI：

```
拉取 https://github.com/Yozily/ai-delivery 的 pgtool/next-preview 目录，
安装其中的 skills/pgtool，
然后阅读该目录下的 README、docs 与 references，告诉我你能用它做什么、有哪些操作是不允许的。
```

## 这套材料能做什么

| 能 | 不能 |
| --- | --- |
| 说明当前工单、产品型号、产线身份与环境 | 修改测试流程 |
| 概括测试流程的主要步骤 | 启动、停止、终止或重试测试 |
| 判断部署是否晚于流程最后修改（方向性结论） | 重试记录同步 |
| 定位最近一次失败的运行与失败组，区分取消与测量超差 | 读取设备在线状态 |
| 归纳记录同步失败的原因与处理方 | 确定本机当前使用的是哪一条部署 |
| 按清单检查能否开始测试 | |

**本版本只读。** 所有操作只读取信息，不会改变你的产品配置。

## 内容

| 形态 | 名称 | 用途 |
| --- | --- | --- |
| Skill | `pgtool` | 了解 PgTool，读取环境、流程、部署、执行、记录与同步信息，协助诊断问题 |
| 文档 | `docs/connect.md` | 给 AI 配置只读 HTTP 工具与服务地址 |

## 前提

- 你的 PgTool 为 v3.0.1 之后的开发构建，桌面端正在运行。
- 你的 AI 宿主能发 HTTP GET 请求（内置网页抓取、通用抓取类 MCP，或命令行工具），并知道 PgTool 服务地址。配置方法见 [docs/connect.md](docs/connect.md)。
- PgTool 接口在本机提供，当前没有访问认证；不要把服务地址暴露到不受控的网络。
