# 连接 PgTool：给 AI 一个只读 HTTP 工具

本版本的 `pgtool` 技能通过 PgTool 桌面端的 HTTP 接口读取信息，只用 GET 请求。你的 AI 需要一个能发 GET 请求的工具，并知道服务地址。

## 1. 服务地址

PgTool 桌面端运行后在本机提供 HTTP 服务。服务地址（主机与端口）由你的 PgTool 管理员提供。验证方法：在浏览器打开 `<服务地址>/api/shell/readiness`，返回中 `status` 为 `ready` 即可用。

把服务地址告诉 AI，例如写进对话的第一句或 Agent 的系统提示词：

```
PgTool 服务地址：<服务地址>。只用 GET 读取。
```

## 2. 只读 HTTP 工具

按你的 AI 宿主选择一种：

| 宿主 | 做法 |
| --- | --- |
| 自带网页抓取工具的宿主 | 先让 AI 抓取 `<服务地址>/api/shell/readiness`，能拿到 JSON 即可用。部分宿主禁止访问本机地址，此时换下一种 |
| 支持 MCP 的宿主 | 添加一个通用的抓取类 MCP 服务器，例如开源的 `mcp-server-fetch`（外部资源，stdio 方式，命令 `uvx mcp-server-fetch`）。它会分段返回长内容 |
| 能执行命令的宿主 | 可用 `curl` 发 GET 请求；建议在权限设置中只放行 GET |

## 3. 使用边界

- 本版本只读。技能不会要求 AI 发出写请求；请在宿主中保持「调用工具前确认」。
- PgTool 的接口在本机提供，不要把服务地址暴露到不受控的网络。
- 部分接口返回内容很大。工具若限制返回长度，AI 会只看到一部分，技能已说明如何应对。
