# 能力现状

「可用」指接口存在且实测能读到；「受限」指能读但有明确限制；「不可用」指当前没有办法。本版本只读。

## 客户端

| 业务域 | 能力 | 状态 | 说明 |
|---|---|---|---|
| 生产现场 | 环境、产线身份、工单 | 可用 | |
| 生产现场 | 产品定义与生产配置是否绑定 | 受限 | 只能从生产上下文字段是否为空判断 |
| 生产现场 | 产品型号目录 | 不可用 | 当前返回空 |
| 生产现场 | 型号与项目的对应 | 不可用 | 没有字段关联；只能看到本机实际在用的项目 |
| 测试流程 | 项目列表 | 受限 | 每项 200–400KB，常常读不全 |
| 测试流程 | 流程大纲与节点 | 可用 | |
| 测试流程 | 部署列表 | 受限 | 不分页、按 ID 排序、过滤参数不生效 |
| 测试流程 | 本机当前部署 | 受限 | 没有直接接口；从最近记录反推，再查活跃执行确认 |
| 测试流程 | 修改流程 | 不可用 | 只给建议，由用户在编辑器中修改 |
| 测试运行 | 执行列表、全部活跃执行 | 不可用 | 只能按已知部署逐个查 |
| 测试运行 | 活跃执行、工作台、调试快照 | 受限 | 依赖部署 ID 与哈希；已结束的执行可能返回会话绑定不存在 |
| 测试运行 | 死信事件 | 受限 | 服务重启后可能为空 |
| 测试运行 | 设备在线状态 | 不可用 | |
| 测试运行 | 启动、停止、终止、重试测试 | 不可用 | 本版本不开放，一律请用户在界面操作 |
| 测试记录 | 记录检索与读取 | 受限 | 单条很大，结论字段在末尾常被截断；无单条读取接口 |
| 测试记录 | 本机条数统计 | 可用 | |
| 测试记录 | 本机合格率 | 不可用 | 本机统计只给条数，不分合格与不合格 |
| 记录同步 | 同步状态与失败原因 | 可用 | 汇总不含错误码分组，需翻页归纳 |
| 记录同步 | 同步重试 | 不可用 | 由用户在界面操作 |

## 云后台

本版本没有云后台接口。云端记录、全线统计与合格率、其他电脑的上传情况、产品定义与产线身份管理，都请用户在 PgTool 云后台查看。
