# PgTool 概念

## 1. 它是什么

PgTool 是产品测试工具链。它把四件事连成一条业务线：

1. 准备测试内容：定义测试流程、变量、设备参数、测试标准，并发布部署。
2. 现场执行：在产线启动测试会话，工位触发测试，实时显示结果并处理交互。
3. 留存记录：每次工位测试的终态形成正式测试记录，可检索、追溯。
4. 同步与统计：记录同步到云端，做订单、合格率等集中统计。

## 2. 两个部分

| | 客户端（桌面产测端） | 云后台（生产云） |
|---|---|---|
| 在哪里运行 | 每台产线电脑本机 | 集中部署的服务器 |
| 主要使用者 | 测试员、现场操作人员、测试方案维护人员 | 生产与质量人员、管理员 |
| 负责 | 测试流程编辑、发布与部署、测试执行、本机测试记录、同步队列、设备接入 | 汇总各电脑上传的记录、集中统计、产品定义与产线身份管理 |
| 数据范围 | 只有这台电脑 | 所有已上传的电脑与产线 |
| 对应技能 | `pgtool-client` | 暂未提供 |

两者的连接点是「记录同步」：客户端把本机测试记录排进同步队列，上传到云后台。同步失败的原因常在云后台或身份服务一侧，但队列和失败记录在客户端能看到。

## 3. 对象归属

| 对象 | 由哪一部分负责 | 在客户端能看到什么 |
|---|---|---|
| 测试流程项目、发布、部署 | 客户端 | 全部 |
| 测试执行、工作台、调试快照 | 客户端 | 全部 |
| 测试记录 | 客户端产生，上传云后台 | 这台电脑产生的记录 |
| 同步队列 | 客户端 | 这台电脑待上传与失败的记录及原因 |
| 当前工单与生产上下文 | 客户端使用，工单与配置信息来自上游 | 当前工单、产品型号、操作员、产品定义与生产配置是否已绑定 |
| 产线身份 | 云后台登记，客户端持有 | 这台电脑的身份状态 |
| 产品定义 | 云后台管理 | 只能看到本机是否已绑定 |
| 云端记录、集中统计、合格率 | 云后台 | 看不到；客户端统计只含本机记录 |

## 4. 谁在用

| 角色 | 目标 |
|---|---|
| 测试方案维护人员 | 管理项目、编辑调试流程、发布部署 |
| 现场操作人员 | 启动会话、工位操作、查看反馈 |
| 生产与质量人员 | 记录查询、统计 |

你协助的主要是测试员和生产工程师：看问题、调试测试流程。你不是开发人员，不需要也不应当依赖源码。

## 5. 业务主线

准备测试内容 → 选择并启动会话 → 工位触发与执行 → 结果记录 → 同步上云与统计。前四步在客户端，统计在云后台。

- 启动会话不等于创建工位的一次测试运行。停止会话、终止工位、重试是三种不同操作。
- 记录以工位运行终态为粒度，没有工位运行的空会话不产生记录。
- 烧录、标贴不在本工具包范围。

## 6. 九个业务模块

| 模块 | 管什么 | 主要在哪一部分 |
|---|---|---|
| 01 测试会话管理 | 启动停止、工位触发与终止、重试重跑 | 客户端 |
| 02 测试执行呈现 | 工位与测试项、结果汇总、交互弹窗、诊断 | 客户端 |
| 03 测试内容准备 | 项目、流程、测试标准、变量资源、调试、发布部署、本地绑定 | 客户端 |
| 04 测试结果与记录 | 记录留存、检索、分析、备份恢复 | 客户端 |
| 05 生产统计与质量 | 订单统计、测试统计、统计口径、云端统计 | 云后台为主 |
| 06 记录同步与上云 | 同步队列、失败重试、离线记录包 | 两者之间 |
| 07 设备接入与仪器集成 | 设备状态、连接配置 | 客户端 |
| 08 产线身份与产品定义 | 产线身份、产品定义、设备 ID 分配 | 云后台为主 |
| 09 应用壳与系统支撑 | 程序选择、主题语言、系统状态、宿主设置 | 客户端 |

## 7. 关键对象与生命周期

```text
作者态项目 → 校验/编译 → 调试 → 不可变 Release → Deployment → 本地绑定 → 测试会话
  → 运行终态事实 → 正式测试记录 → 同步 → 统计与质量
```

必须区分，它们不是同一个东西：

```text
流程定义 ≠ Release ≠ Deployment ≠ 运行会话 ≠ 测试记录 ≠ 统计结果
```

- 项目是正在编辑的版本；Release 是发布后不可变的版本；Deployment 是 Release 在某台电脑上的部署。
- 产线身份、产品定义、设备连接是启动测试的前提。
- 「版本」有三种含义：作者态的当前版本、已发布的版本、实际生效的版本。引用时说清是哪一种。

## 8. 使用边界

通用规则见 pgtool 技能的 SKILL.md。补充：服务端会强制互锁、占用、版本冲突和权限校验，这些拒绝是保护，不是故障。
